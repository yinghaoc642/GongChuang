# M1-M7 全速度与加速度提高 50% 前的独立基线

此备份只服务于“撤销全部电机速度和加速度 +50%”，不包含也不应撤销后续几何修改：

- M6 近侧允许到逻辑 `-8 mm`，保留距物理硬限位 `2 mm`。
- 料盘夹取 M6 伸长最终改为 `1 mm`。
- 圆环回收至料盘时，M7 在圆环源位额外下降 `3 mm`夹取。

速度基线：

- M1-M4：路线、扫码、转向、纠偏、工位和精确到位的全部最大步频保持本目录创建时的代码值。
- M5：默认 `1000`，端点 `45000/67500/101250`，搬运 `117000/100800/108000/117000` step/s。
- M6：默认串行 `60`，常规/原料/放置/返回 `390/420/450/648` RPM；端点精调/粗调/恢复/上电归零 `160/240/120/100` RPM。
- M7：默认串行 `60`，常规/软归零/返回/圆环放置/端点精调/恢复/上电归零 `3744/1200/4493/1800/2496/1200/100` RPM。

加速度基线：M1-M5恢复各自本次实验前的线性步频加速度；M6/M7恢复EMM原始加速度字节。恢复时不会修改坐标、延时或并行关系。

`restore_all_motor_speeds.patch` 是供 Codex 使用的定向 `apply_patch` 逆向补丁，只恢复速度、加速度及相应测试断言。它不修改坐标、延时或动作并行关系。
