# 高处、手持相机识别复测

用户将相机移到高处后要求复测；此前说明用手拿相机、可能抖动。没有测量物理高度，也没有移动机械臂或底盘。

## 实测

- 使用安装模型331476与正常系统配套运行库，生产conf_th=0.70、iou_th=0.45不变。
- 采样500帧，13.577秒，进程退出0。
- 正式门槛有框0/500，几何接受0/500，稳定输出0/500。
- 每5帧额外作一次0.20门槛诊断，100次中60次有候选，全部候选分数范围0.208172～0.409690；这些诊断候选没有进入正式结果。
- 人工查看原图确认三个编号均清楚可见。部分标为2r的候选实际框住右侧3号圈。例如首帧分数0.380755的框x=200/y=77/w=85/h=100落在3号圈；同帧中间2号圈候选分数约0.264354。
- 所有正式拒绝均已发生在0.70置信度门槛处，尚未进入几何或相邻帧稳定判定。因此不能用手抖触发3px稳定条件解释本轮无输出；手持对置信度的影响仍未单独量化。
- 复测后已自动恢复持续预览。
