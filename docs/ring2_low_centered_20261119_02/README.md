# 低位居中、手持相机识别复测

用户说明当前高度较低，随后补充相机用手拿着，可能抖动。因此不是固定相机实验，也不代表正式高位粗定位的姿态。

## 实测

- 正式模型331476，正式conf_th=0.70、iou_th=0.45，未改生产脚本或阈值。
- 100帧耗时9.982秒，退出码0。
- 100/100帧有达到0.70的检测，100/100帧通过正式几何候选筛选。
- 42/100帧给出连续两帧稳定坐标。当前稳定条件为相邻两帧中心x/y和半径r变化都不超过3px。
- 检测分数范围0.715402～0.926287。稳定输出中x=158～187、y=105～137、半径57～64像素。
- 日志未见模型崩溃。复测结束后已自动恢复带中心十字的持续预览，预览最多运行10分钟，可用相机退出按钮退出。

## 限制

手持画面位移与霍夫圆细化波动均可能触发3px稳定限制。本轮未记录所有稳定判定前候选，不能把两者的影响分别量化；42/100不是识别准确率或实际任务成功率。没有实际高位/工位标定、没有验证纸张外圈实际尺寸，没有发送协议或运动命令。
