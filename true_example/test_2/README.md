# 暂存区定位与放置独立测试

本工程只保留正式 `src/main.cpp` 中与暂存区有关的动作：

1. 机械臂恢复标准作业姿态；
2. 到原 1 号圈位置，M7 先下降到 `-90 mm`，再请求 `AA 09 BB`；
3. 用 M5/M6 闭环修正到圆心误差不超过 3 像素，并记录 1 号圈坐标；
4. 抬升、缩回后对 3 号圈重复上述过程；
5. 将 1、3 号圈的圆柱坐标转换为平面坐标，取中点得到 2 号圈坐标；
6. 依次从载物盘三个槽位取料并放到设定的圈位；
7. 载物盘回 165°，机械臂回行驶姿态。

释放高度保留两级各 `5 mm` 的少下降补偿，且第二级补偿对三个圈全部
生效。因此第一轮三个圈的实际高度均为 `-140 mm`，第二轮均为
`-80 mm`。

## 使用前

- 将底盘停稳在暂存区正式作业位置；测试中底盘公共使能 PE13 始终保持高电平，M1～M4 不会动作。
- 上电前人工确认：M5 在旧坐标 0° 行驶姿态、M6 完全缩回、M7 位于最高点。
- 确认 MaixCAM 正在运行与正式程序匹配的视觉脚本，霍夫圆模式返回一行 `9,x,y`。
- 在 `src/main.cpp` 顶部设置：
  - `TEST_STORAGE_ROUND`：`1` 对应第一轮高度，`2` 对应第二轮高度；
  - `TEST_RING_ORDER`：三个载物盘槽位依次要放到的圈号。

短按 PB9 开始；运行中长按 PB9 急停。发生急停或故障后，软件坐标不再可信，必须断电并人工恢复上述机械零位后再试。

仅编译：

```powershell
pio run -d true_example/test_2
```
