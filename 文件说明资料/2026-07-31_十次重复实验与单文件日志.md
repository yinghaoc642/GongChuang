# 十次重复实验与单文件日志

圆环板、S12/S23实测值、M6指针毫米尺、H0和Z0均沿用现有装置，不再重复安装。本轮不设置上电后固定等待60秒，也不要求人工抄写或复制每次日志。

## 1. 启动一个连续日志文件

在工程根目录打开PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\start_10_run_logger.ps1
```

如果电脑同时有多个串口，指定调试串口，例如：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\start_10_run_logger.ps1 -Port COM5
```

脚本使用115200波特率，在控制器断电、上电和串口重新连接时继续写同一个文件。所有固件原始日志前都会增加电脑时间戳和`RUN 01`～`RUN 10`标签。

日志保存在：

```text
experiment_logs/rough_repeat_YYYYMMDD_HHMMSS.log
```

最新日志的完整路径保存在：

```text
experiment_logs/LATEST.txt
```

## 2. 十次运行

1. 保持底盘、圆环板、相机、光源和已有标尺不动；
2. 启动上述日志脚本，看到`SERIAL CONNECTED`后开始；
3. 上电后直接按原流程单击PB9，程序自己的零位安全门会拒绝无效启动；
4. 完成或故障后断电，按现有方法把M6/M7恢复到机械起点；
5. 再次上电并运行，直到脚本自动记录10次终态；
6. 失败也保留在同一个日志中，不删除、不覆盖、不用同一编号伪装重跑；
7. 第10次出现成功或故障终态后，脚本自动退出。

如需提前停止，按`Ctrl+C`，已经收到的内容仍会保留。

## 3. 完成后

只需说明“十次跑完了”。分析程序会读取`experiment_logs/LATEST.txt`指向的完整日志，不需要逐个复制日志。

将从同一个文件中提取：

- 每次M6/M7零位探测比和10 mm全程比；
- P1/P2/P3坐标、P2 M5/M6；
- 两端跨度、轴线角度、半径、置信度和像素误差；
- 放置、抓回、并行动作的分段时间；
- 十次成功率、重复范围、标准差、离群点和单调漂移；
- 新并行流程相对旧五次97秒基线的耗时变化。
