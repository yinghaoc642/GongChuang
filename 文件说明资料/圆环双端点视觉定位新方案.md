# 圆环双端点视觉定位新方案

## 结论

正式方案改为“底盘冻结后，机械臂分别观察 1 号和 3 号圆，建立圆环在
机械臂坐标系中的实际二维位置；2 号由两个端点求出”。不再要求车体与
`1-2-3` 圆心连线平行，也不再把左右圆固定写成中间圆的横向
`±150 mm`。

正常流程只观察两个圆，不逐个观察三个圆。只有端点数据不一致时，才追加
观察 2 号圆进行异常判断。

## 当前方案为什么会歪

当前 `ringPose()` 固定使用：

```text
1号：(X,Y) = (135, +150) mm
2号：(X,Y) = (135,    0) mm
3号：(X,Y) = (135, -150) mm
```

其中 `X` 是机械臂向外方向，`Y` 是逆时针切向方向。由此得到：

```text
1号：M5约 +48.013°，M6约 66.804 mm
2号：M5为   0.000°，M6为  0.000 mm
3号：M5约 -48.013°，M6约 66.804 mm
```

这等价于假设车辆与三圆中心线完全平行。当前视觉只把 2 号圆平移到画面
中心，没有观测三圆中心线的角度。若车与三圆线有偏角 `δ`，外圆误差约为：

```text
外圆误差 ≈ 150 × sin(δ)
1° -> 2.62 mm
3° -> 7.85 mm
5° -> 13.1 mm
```

因此中间圆可能准确，但 1、3 号会向相反方向偏。这不是调一个固定补偿量
能够彻底解决的问题。

## 与历年方案的关系

2025 年参考代码已经包含以下优点：

- 用视觉驱动 M5/M6 对准圆心；
- 记录机械臂实际角度和伸长量；
- 用余弦定理、`atan2` 和勾股定理计算未观察位置；
- 利用已知圆间距检查机械臂零长度。

参考代码通常观察“中间圆 + 一个侧圆”，再外推出另一侧圆。若两次观测的
二维误差标准差都是 `σ`，外推点 `P3 = 2P2 - P1` 的误差约为
`sqrt(5)σ`，而且只有 `150 mm` 的方向基线。

本方案改为直接观察 1、3 两个端点，方向基线为 `300 mm`；1、3 直接测量，
2 号取中点。这样比“中间 + 一侧”更对称，误差条件更好，也能直接检查
两端距离是否合理。

## 正常工作流程

### 1. 底盘先稳定，然后完全冻结

车辆到达工位后，先完成刹停和必要的 IMU 航向稳定。随后锁住底盘，在
端点建图、三件放下以及粗加工重新抓回结束之前，底盘不得再平移或旋转。

现有 `startPostVisionHeadingCorrection()` 不能放在端点测量之后执行；否则
刚记录的两个圆心会因车体旋转而立即失效。航向锁必须前移到扫描之前。

### 2. 观察 1 号圆

机械臂使用原来的 `M5≈+48°、M6≈66.8 mm` 作为搜索起点，但这只是一项
搜索先验，不再作为最终放料位置。

安全动作顺序：

```text
M7升高 -> M6回零 -> M5转向1号附近 -> M6伸到搜索长度
-> M7降到固定视觉高度 -> 检测唯一的主外环
```

MaixCAM 不识别数字“1”，而是复用 v5.1 的外环尺寸过滤，在当前搜索窗口
中选择靠近画面中心、半径占主导且连续稳定的真实外圆。圆号由 STM32 当前
“正在扫描1号”的状态赋予，避免数字笔画再次参与编号。

若圆心残差已经很小，直接换算并记录。若残差较大，机械臂自身进行一次
M5/M6视觉修正，再确认圆心；底盘不动。目标是在记录前让圆心进入
`3 px` 范围。

### 3. 观察 3 号圆

抬高 M7 后安全转移到 3 号名义附近，使用同样方法得到 3 号实际圆心。
若结构实测确认在视觉高度横扫不会碰撞，后续才可省略部分升降动作以节省
时间，第一版不能直接假设安全。

### 4. 建立三圆实际几何

将两个圆心转换到以 M5 转轴为原点的二维坐标：

```text
P1 = (X1,Y1)
P3 = (X3,Y3)
D  = |P3-P1|
u  = (P3-P1)/D
P2 = (P1+P3)/2                  # 等间距时
```

生产版应先实测比赛圆板的相邻圆心间距 `S12`、`S23`。若两段不完全相等：

```text
P2 = P1 + S12/(S12+S23) × (P3-P1)
```

若已确认真实布局严格等距，且相邻实测间距为 `S`，可用最小二乘约束消除
端点测量噪声：

```text
M  = (P1+P3)/2
T1 = M - S×u
T2 = M
T3 = M + S×u
```

在尚未实测真实圆距之前，不盲目强制使用 `150 mm`；先保留直接测得的
两个端点，并把名义 `300 mm` 只作为质量检查。

### 5. 对每个圆分别做逆运动学

对机械臂坐标中的任意目标 `Pi=(Xi,Yi)`：

```text
半径 ρi = hypot(Xi,Yi)
M5角度 = atan2(Yi,Xi)
M6长度 = ρi - L0
```

完全回缩时的永久实测尺寸为 `125.74 mm`。为避免M6回到机械硬限位堵转，
上电后程序先前伸10 mm并把该点设为工作零点，所以运动学实际采用
`L0=125.74+10=135.74 mm`。当前代码同时假设相机光心和夹爪中心具有
相同径向距离；若后续测得二者不重合，必须加入独立二维工具偏置。
工作零点下M6必须满足：

```text
0 mm <= M6 <= 140 mm
```

M7也采用相同的安全零点原则：上电前人工置于物理最高点，上电后自动向下
移动10 mm并把该点设为逻辑0。为保持原来的实际作业高度不变，后续命令为：

```text
原料抓取：逻辑下降63 mm = 物理下降73 mm
圆视觉：  逻辑下降80 mm = 物理下降90 mm
料盘取放：逻辑下降30 mm = 物理下降40 mm
粗加工/第一轮暂存：逻辑下降145 mm = 物理下降155 mm
第二轮暂存：逻辑下降80 mm = 物理下降90 mm
```

还应增加当前代码尚未具备的 M5 实机安全角限制，避免电缆和结构碰撞。
M7仍使用现有放料高度和最后 `20 mm` 慢速下降方案。

### 6. 复用同一张圆环坐标表

每次到达一个工位后只建图一次，得到：

```text
measuredRingPoses[1]
measuredRingPoses[2]
measuredRingPoses[3]
```

三次放料、粗加工后的三次抓回都复用这一组位置，不在每件物料前重复视觉
识别。车辆再次到达粗加工区或到达暂存区时，必须重新建图，不能跨工位或
跨次到达复用。

## 像素坐标到机械臂坐标

设扫描时：

```text
M5角度 = θs
M6伸长 = es
相机中心半径 ρs = L0 + es
图像偏差 dx = x-160，dy = y-120
```

在现有符号约定下，局部近似为：

```text
向外偏移 du = -sy×dy
逆时针切向偏移 dv = -sx×dx
```

旋转到机械臂基座坐标：

```text
X = (ρs+du)cosθs - dv sinθs
Y = (ρs+du)sinθs + dv cosθs
```

现有单一比例 `35/72 mm/px` 只在标准姿态和固定高度下是经验值。相机随
M5旋转以后，正式版应使用固定视觉高度标定得到的二维雅可比或单应性。
最稳妥的办法是先用机械臂把圆心伺服到画面中心，使剩余像素修正很小，再
记录M5/M6位置；这样最终精度不强依赖一个未经验证的全画面比例。

## 视觉协议调整

建议新增一个“端点单圆”请求模式，例如 `mode 10`：

- 复用 v5.1 的数字小圆过滤；
- 不调用“从三圆中返回中间成员”的 `select_center_ring()`；
- 只选择当前搜索窗口中靠近中心、半径占主导、无同尺度歧义的外圆；
- 保留0.5秒、多帧跨度和半径稳定检查；
- 圆号由 STM32 扫描阶段赋值，不做数字OCR。

原 `mode 9` 可保留为异常回退时的中间圆识别模式。

## 时间设计

正常路径只有两个稳定窗口：

```text
1号稳定识别约0.5 s
3号稳定识别约0.5 s
```

比当前单圆方案只多一个视觉窗口。机械臂到端点及端点间切换预计增加约
`1~2 s`，但新方案取消底盘最多多次视觉平移修正和测量后的航向回正，实际
总时间可能接近当前方案。目标是：

```text
正常端点建图 P95 <= 3 s
异常回退总时间 <= 5 s
```

必须用串口时间戳实测，不凭估计继续压缩稳定窗口。

当前低头标定的横向视野约为：

```text
320 × 35/72 ≈ 156 mm
```

而1到3圆心相距约 `300 mm`，所以低头状态不可能一帧同时看到两个端点。
抬高相机可能扩大视野，但会减小圆半径、放大镜头畸变和数字干扰；只有
实测证明高位画面能完整保留1、3外圆及边缘余量后，才把“一帧看两端”
作为后续加速项，不能作为第一版主方案。

## 质量检查与失败回退

端点建图完成后必须同时检查：

- 两端距离接近实测总间距，初始质量门限建议 `|D-(S12+S23)| <= 5~8 mm`；
- 1号位于预期一侧、3号位于另一侧，没有调换；
- 两端圆半径比例和稳定置信度合理；
- 三个目标均在 M5/M6/M7 的实机安全工作空间内；
- 测量后底盘没有发生任何位移或转动。

失败处理按以下顺序进行：

1. 原位置重新稳定识别一次；
2. 在预测位置附近进行有界的M5/M6小范围搜索，底盘仍不动；
3. 两端数据冲突时才追加观察2号，用三点拟合并剔除离群点；
4. 只有一个端点最终失败时，使用“2号 + 已找到端点”降级推算另一端；
5. 全部失败才进入旧中圆方案或安全报错，不能无限等待，也不能无提示地
   使用未经验证的固定姿态。

## 机械重复性要求

新几何方案能消除车辆不平行造成的系统误差，但不能自动消除关节回差。

- M6观察和放料都应从回缩侧向外伸，保证逼近方向一致；
- M5观察某圆和后来放/抓该圆时，应通过固定预置角从同一方向逼近；
- 相机中心与夹爪释放中心必须做二维手眼偏置标定；
- 放料继续使用最后20 mm慢速下降及到位消振；
- 若重复试验随机波动仍超过5 mm，应先处理结构、回差、夹爪释放和底盘
  刹停，而不是继续叠加视觉补偿。

## 实施前只需要确认的实机条件

1. M7在视觉高度时，机械臂从1号搜索位转向3号是否会碰圆环、台面或车体；
2. 相机光轴中心与夹爪释放中心的平面偏移量；
3. 实物 `1-2` 和 `2-3` 圆心间距；
4. 车辆按正常到站误差摆放时，1、3号是否都落在各自名义搜索位的相机
   视野内。

确认这四项后，再修改STM32状态机和MaixCAM端点模式，风险最低。

## 验证方案

故意将车辆设置为：

```text
yaw = -10°、-5°、0°、+5°、+10°
并叠加横纵向 ±20~40 mm 偏移
```

每种至少测试10次，记录：

- P1、P3、两端距离D和拟合出的圆心线角度；
- 三个目标M5/M6；
- 两次识别耗时和总建图耗时；
- 三个物料最终X/Y误差；
- 重试/降级次数。

验收重点不是只看平均值，而是确认1、3号误差不再随车辆yaw呈相反方向
变化。初始建议目标：

```text
端点建图成功率 >= 99%
两端距离误差P95 <= 5 mm
单环放置误差P95 <= 3 mm，最大 <= 4 mm
正常建图耗时P95 <= 3 s
```
