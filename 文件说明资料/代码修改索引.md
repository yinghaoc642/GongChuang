# 工创主控代码修改索引

这份索引只回答一个问题：以后出现实车问题，应该改哪个文件。

## 总原则

- 物理硬件参数只允许存在于 `lib/RobotConfig/src/RobotConfig.h`。
- 串口协议和字节解析放在对应硬件库，比赛流程不得直接读写协议字节。
- `src/main.cpp`负责比赛状态机和模块调度，不再新增硬件协议实现。
- 原料、粗加工、暂存的规则分别修改，公共抓放动作不得复制三份。
- 一次提交只做“结构迁移”或“动作参数/逻辑修改”中的一种，避免实车时序变化
  被重构噪声掩盖。

## 当前模块调用关系

```text
src/main.cpp
├─ RobotConfig          运行模式和唯一硬件参数源
├─ ArmTransferPlanner   抓放姿态与速度档规划
├─ ImuHeadingTracker    JY901连续航向
├─ MaixCamClient        MaixCAM非阻塞通信
├─ ArmMotorController   M5
├─ CompetitionCore      二维码任务规则
├─ VisionProtocol       由MaixCamClient内部使用
└─ MecanumKinematics    底盘运动学
```
