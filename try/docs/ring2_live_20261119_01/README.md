# 2号圈第一次相机端识别采样

用户确认相机已连接并能看到2号圈，相机保持与STM32断开。此轮只运行独立诊断脚本，没有更改安装应用、模型、视觉协议、训练集或验证集，没有发送机器人请求/响应。

## 实测

- 相机320×240，安装模型331476，使用已修复的正常系统运行库。
- 生产Ring2Detector调用保持原参数：conf_th=0.70、iou_th=0.45。记录代理仅保存原调用结果，不改变参数或返回对象。
- 40帧耗时1.572秒，程序退出码0。
- 正式0.70门槛下有框0/40，几何接受0/40，稳定输出0/40。
- 每5帧额外诊断一次0.20门槛，共8次，8次都有候选。这些结果没有进入正式检测器、协议输出或运动控制。
- 根据保存图像人工确认：中间目标为2号圈，左边为1号圈，右边为3号圈；纸面/圈位于画面下方，拍摄有倾斜。
- 对应中间2号圈的8次诊断候选分数范围0.380751～0.674891。左边1号圈也被错误标为2r，候选分数最高0.575092。

## 判断与下一步

本场景中模型确实能产生2号圈候选，但置信度未过正式门槛，且存在其它编号误检。因此目前不能进入底盘闭环粗定位，也没有证据支持直接放宽门槛。先手动将2号圈移至画面中心、保持完整外圆并正对纸面后复测，区分取景影响与模型泛化不足。如果仍失败，再在不改变既有训练/验证集的前提下评估独立模型候选或准备新增独立采样数据。

只有一个静止场景、1.572秒样本，不能推算实际识别成功率或比赛工位表现；当前纸张也尚未证明等同于真实工位的高位相机姿态。
