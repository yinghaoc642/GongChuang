# 2 号圈粗定位训练资料

资料来源是 MaixHub 项目 137925 的数据集 146275（“2号圈-2”）。下载包和原始 VOC 标注已归档在本目录。`dataset_audit.json` 是对原始文件的审计：服务器记录为 42 train/12 val；按图像字节 SHA-256 去重后为 train 14、val 6，train/val 的相同字节哈希数为 0。重复文件来自数据集内部的复制命名，不能把服务器的 54 张直接当成 54 个独立场景。

`prepare_yolo_dataset.py` 将 VOC 标注转换成 YOLO 文本格式，保留原 split，发现跨 split 字节重复会中止，输出写入 `dataset_yolo_unique/`。`data.yaml` 的类别为 `2r`。这套资料适合继续训练，但只有高位、真实补光和真实遮挡采集后才能判断比赛视角效果。

## 模型目录

- `../../models/ring2/historical_311465/`：历史可下载模型和官方报告，原模型标签为 `2r`。
- `../../models/ring2/trained_331358/`：本轮448×448新模型和原始报告，ZIP另存且未覆盖历史模型。
- `../../deploy/ring2/`：默认仍选历史224×224模型。新模型报告抽样3张的score为0.6211/0.6840/0.5671，均低于代码0.70门槛，旧模型抽样有2/3高于门槛；这只是三张抽样，不能代替完整评估。
- `../../deploy/ring2_new_331358/`：独立新模型候选，可按部署README切换。两种模型均未在新高位姿态验证。
- `../../capture_ring2.py`：在高位姿态手动拍摄 60 张、每秒一张的脚本；不发送机器人控制命令。

材料包视频是外部整车拍摄，不是机械臂相机圈2视角，没有截取它混入训练。本轮未连接实机相机流，未采新高位图片。
