# 1/2/3号圈独立补充采集包

本目录独立于全部既有训练集和验证集。当前仅保存三个已采集场景的参考图，不代表已有足够训练数据；未标注、未划分、未上传、未训练。

目标类别为1r、2r、3r。标签框应包住对应编号的完整物理外圈，三个类别必须采用一致边界定义。混合画面中的三个完整目标都要标注，不能把未标注的其它编号隐式当作负样本；不完整、遮挡、模糊或无法确认编号的目标先放待审，不猜标签。现有程序只接受2r/ring2/2，导出三类模型后也只将2r交给粗定位。

采集应包含同样视角下的三个编号：高位/低位、居中/周边、实际可用距离、轻度角度与照明变化，以及单圈/三圈同框。正式高位工位画面是重点。连续帧不是独立场景，需筛选清晰且有变化的帧；一个采集场景整体进入同一个数据子集，避免相邻画面泄漏。已有训练集和验证集不改动，后续新实验使用本目录的独立数据版本。

数据增强只能在新训练部分生成；新增验证场景必须保持原始画面，不能用同一原图的增强副本作为独立验证。采集到1、3号误检样本有帮助，但也必须补充同距离/角度的2号圈正样本。
