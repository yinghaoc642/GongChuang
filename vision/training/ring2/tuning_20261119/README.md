## 推荐及边界

优先实机验证候选：331402（224×224，batch4，lr0.001，无随机增强）。报告抽样3/3通过，三张IoU约0.833/0.854/0.881，框中心偏差0/10.55/5.32源图像素。这里只核查了报告坐标，不能将像素偏差直接称为实际底盘毫米误差。最小score=0.708066，距0.70门槛仅约0.008。

331405同样有3/3通过score门槛，但它在16.jpg上的预测框212×159，宽高比1.333333，直接代入现有box_candidate会超过1.33上限。331402的三张在原报告坐标下均通过该函数。然而原始数据图片为416×234，相机脚本为320×240；该静态回放不能证明真实相机输出或完整检测流程表现。未修改几何门槛或降低0.70置信度门槛来让结果过关。

各报告随机展示的图片不完全相同，每组只训练一次，不能严格据此认定某种增强或更大分辨率必然降低准确率。可证实的是本轮得到的这些模型在已公开样本上的具体结果。平台val_acc相同，无法单凭1.0判断运行门槛下的漏检情况。

已将推荐候选独立准备到 `../../../deploy/ring2_tuned_331402/`，包含配对的model.mud和cvimodel；旧默认仍为311465，旧模型与其他存档保留。没有上传或烧录硬件，也没有修改STM32或视觉运行代码。
